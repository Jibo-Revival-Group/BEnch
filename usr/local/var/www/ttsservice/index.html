TTS XML Markup Support with examples

<speak>

The speak tag defines the begin and end of markup. All supported tags should be inside speak tag.

<speak> This is a test. </speak>

<break>

The break tag allows insertion of arbitrary pauses. The value is in seconds and takes a float.

<speak> This is a <break size="1.5"/> test. </speak>

<audio>

The audio tag provides a means to insert an external audio clip. The supported format is - RIFF (little-endian) data, WAVE audio, Microsoft PCM, 16 bit, mono 16000 Hz

<speak> This is a <audio src="/opt/data/audio/beep.wav"/> test. </speak>

<phoneme>

The phoneme tag allows the user to provide customized pronounciations for words.

<speak> This is a <phoneme ph="l eh k s ih k ah n"> lexicon </phoneme> test. </speak>

<duration>

This allows stretching and shrinking of a piece of text wrapped within duration tag.

The duration tag as 2 types of attributes: "stretch" and "set".
stretch: as the name implies will stretch the speech by the set value. If the value is less than 1 it will actually shrink the speech (speak faster)
set: this will ensure the speech is bounded for a set duration period. The unit of "set" is in seconds. In the following examples the word "so" will be spoken exactly for 2.3 seconds:

<speak> This is <duration stretch="3">so </duration> good. </speak>
<speak> This is <duration set="2.3">so </duration> good. </speak>

<pitch>

This enables increase/decrease in pitch. There are 2 attributes: "add" and "mult"

add: this attribute takes frequency in hertz as a parameter and adds it on top of the default.
mult: this value is multiplied on-top of the default predicted pitch frequency. values above 1 will increase the pitch, and values below 1 will decrease it.

Examples: <speak> This is <pitch mult="1.2"> <duration stretch="3">so </duration> </pitch> <duration stretch="1.5">good </duration>. </speak>
<speak> This is <pitch add="200"> <duration stretch="3">so </duration> </pitch> <duration stretch="1.5">good </duration>. </speak>

Note: you can nest pitch and duration with each other, but you cannot nest two pitch or duration tags with itself.

<say-as>

This tag is used to override text normalization rules. It can support any number of attributes. For now we have one - "spell".

spell: this will force the synthesizer to spell a piece of text instead of pronouncing it.

<speak> apple is spelled <say-as spell="apple"/> </speak>

Using "Get TTS Lex"

TTS Lex is an endpoint in TTSService that returns lex rules based individual words for a given text

enter text in the "POST to TTS" filed and it has an optional parameter bool "splitOnApostrophe", that can take on values true or false. Default to false

Using "Get TTS POS Tags"

TTS POS Tags is an endpoint in TTSService that returns POS tags for the list of words entered in "POST to TTS" field

It has an optional parameter bool "splitOnApostrophe", that can take on values true or false. Default to false Example of list of words can be ["micheal","'s","tests","is","n't","running"] or ["michael's","tests","are","isn't","running"]
